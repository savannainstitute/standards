# Hosting

This file records where the app runs, so that someone other than its author
can find it, change it and put back an earlier release. Fill in each section
when the app is first published and keep it current.

## Service

The service that hosts the app, and how a new release reaches it. The service
pulls the default branch itself; this repository holds no deploy workflow and
no deploy secret.

## Account

The account or organization on the service that owns the app. Write the
account's name here, never a password, token or key.

## Address

The address people use to open the app, and any other address that points to
it.

## Who administers it

The role or team that can change the service's settings, and how to reach
them.

## Rolling back

The exact steps that put the previous release back on the service, and how to
tell that it worked.
